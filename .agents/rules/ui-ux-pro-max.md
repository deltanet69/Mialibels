# UI/UX Pro Max Design Guidelines

Always reference and apply **UI/UX Pro Max** design intelligence when building, redesigning, or refining interfaces:
- **Design Intelligence**: Check `.agents/skills/ui-ux-pro-max/references/pro-rules.md` and `quick-reference.md` for UX rules, accessibility standards, color balance, typography hierarchy, micro-interactions, and anti-patterns.
- **Visual Polish**:
  - No emojis as functional icons (always use SVG icons like Lucide / Heroicons).
  - Explicit `cursor-pointer` on all interactive and clickable elements.
  - Proper contrast ratio (minimum 4.5:1 for body text).
  - Smooth micro-transitions and context-aware feedback states (loading, empty, error, success).
  - Responsive layouts tested across 375px (mobile), 768px (tablet), 1024px (laptop), and 1440px (desktop).
