### Email System - SMTP Alternative

# Pilihan Provider SMTP yang Mudah

| Provider              | Kelebihan                                    | Kekurangan                   | 
| ---                   | ---                                          | ---                          |
| Gmail SMTP            | Gratis, mudah setup                          | Limit 500 email/hari         |
| Zoho Mail             | Gratis untuk 1 domain                        | Setup DNS diperlukan         |
| SendGrid              | 100 email/hari gratis, reliable              | Perlu verifikasi domain      |
| SMTP2GO               | 1000 email/bulan gratis, no domain verify    | Setup API key                |
| Mailgun               | 5000 email/bulan gratis (trial)              | Perlu verifikasi             |  


### Rekomendasi: Gmail SMTP (Paling Simpel)

Kenapa Gmail?
✅ Tidak perlu verifikasi domain
✅ Setup 5 menit
✅ Gratis
✅ Cukup untuk notifikasi SPP (50-100 email/bulan)



### Alternatif: SMTP2GO (No Domain Verify)

Kenapa SMTP2GO?
✅ Tidak perlu verifikasi domain
✅ 1000 email/bulan gratis
✅ Setup API key/username
✅ Delivered rate tinggi

### Alternatif Lain: Mailgun (Trial)

Kenapa Mailgun?
✅ 5000 email/bulan gratis (trial)
✅ Reliable untuk notifikasi massal
✅ API + SMTP
⚠️ Tapi tetap perlu verifikasi domain (tapi lebih gampang dari Resend).
