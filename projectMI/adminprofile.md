### Akun admin Mi Attaqwa 15 Babelan

Pada navbar admin dashboard user profile harus memili halaman detail profile masing-masing user akun tersebut, tidak hanya logout saja.Untuk setiap user akun (RBAC) perlu halaman detail akunnya masing-masing, dan di page tersebut terdapat info-info akunnya seperti :
- username, 
- nama lengkap, 
- email, 
- password, 
- role, 
- foto profil,
- riwayat absensi pribadi secara detail (seperti absensi harian, rekap absensi per bulan, dll)
- data kegiatan sekolah (jika user tersebut adalah guru/walikelas) 
dll. 

Selain itu juga terdapat tombol untuk reset password akunnya yang akan menggenerate password baru secara otomatis, atau membuat sesuai yang diinginkan akun tersebut.

Perlu juga ada tanda assigment ke classroom terkait, atu jika user tersebut mengajar lebih dari 1 classroom maka akan ada tanda assigment ke classroom terkait.
