### ID unik untuk siswa

ID ini juga yang nantinya akan di gunakan orang tua sebagai ID login untuk lihat perkembangan / tagihahn SPP sekolah / tabungan siswa pada portal orang tua. 


Jadi orang tua login tidak lagi menggunakan NIS/NISN, tetapi menggunakan ID siswa ini.


Formatnya adaalah sebagai berikut :
{ [Kelas] [Tahun] [Nomor Urut Siswa 3 digit angka] }


Misal kelas 1A, maka : 01A2026001
Misal kelas 5B, maka : 05B2026024

Namun, NISN siswa pada listing/detail siswa tetaplah ada untuk data yang lebih detail tidak perlu dihapus untuk NISN siswa karena ini cukup penting untuk pendataan sekolah.


Maka saat login di halaman portal orang tua, orang tua hanya cukup login menggunakan ID siswa ini. Tidak perlu pakai NIS/NISN lagi. Dan, password standard prang tua tetap "mialibels15" sebagai default yang harus di ganti pada saat awal login kedalam portal orang tua.


ID unik ini juga nantinya akan ada pada kartu siswa/kartu pelajar yang dapat di download melalui portal orang tua dan detail siswa dalam admin dashboard.
